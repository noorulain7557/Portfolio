# Noor-ul-Ain Khalid — Immersive Portfolio

A frontend-only portfolio built as a guided digital galaxy. It presents web and backend skills first, with supporting Android and cybersecurity experience.

## Local development

```bash
pnpm install
pnpm dev
```

## Validation

```bash
pnpm build
pnpm lint
pnpm test
pnpm audit --prod --audit-level high
```

## Deployment

The site is configured for Vercel as a static export. Import this directory as a Vercel project; the build command and output directory are defined in `vercel.json`.

Before publishing on a custom domain, replace the placeholder `https://noorulain.dev` canonical URL in `app/layout.tsx`, `public/robots.txt`, and `public/sitemap.xml` if the final domain differs.

Project concepts are explicitly labeled as reconstructions. Do not remove those labels until the content has been checked against Noor's actual project work.
